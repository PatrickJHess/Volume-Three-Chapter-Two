📡 Accessing price data directly from FedInvest¶

Note on Data Availability: The FedInvest page on the Treasury Direct website provides U.S. Treasury securities data, including the current day’s prices (updated after 1:00 PM New York time) and daily historical prices dating back to September 2008.

The current page design is straightforward, making the data easily accessible using Pandas. As shown below, the page features a form to select the desired date for the prices.

The FEDInvest Function: A specialized function, FEDInvest, is used to retrieve this data. The function takes the requested date as its single argument and returns the data cleanly as a Pandas DataFrame.

Click the image below to watch a brief video explanation of the website and how the FEDInvest function works.

🔧 FedInvest function¶

Why we use a post request: Because the website requires you to submit a form with the Month, Day, and Year (rather than simply putting the date directly into the web address), a standard get request or a simple pd.read_html(url) will not work. Instead, the function uses the post method. It bundles the target month, day, and year into a payload and sends it to the server, essentially mimicking a user clicking the “Show Prices” button. The names of the variables (month, day, and year) are identified by inspecting the site.

🧹 Cleaning the Data¶

Once you have fetched the raw data, you will likely want to format it into a time-series DataFrame that is ready for financial analysis.

Step-by-Step Breakdown:¶

  • Filters for Standard Securities: It looks at the SECURITY TYPE column and filters the dataset to keep only standard Treasury Bills, Notes, and Bonds (ignoring other types like TIPS or Floating Rate Notes).

  • Removes Clutter: It drops the CUSIP and CALL DATE columns that aren’t needed for our analysis.

  • Creates a Time-Series Index: It sets the MATURITY DATE as the index of the DataFrame, converts those dates from standard text into official Pandas datetime objects, and then sorts rows chronologically.

  • Standardizes Financial Terms: It renames the columns to use standard trading terminology, changing RATE to Coupon, BUY to Price Ask, and SELL to Price Bid.

  • Formats Numeric Data: Finally, it removes any percentage signs (%) from columns like Coupon, Price Ask, Price Bid, and YIELD and converts them into floating-point numbers so they can be mathematically analyzed.

🔍 Click to see the clean_FEDInvest function
def clean_FEDInvest(df):


    import pandas as pd
    # Filters for Standard Securities
    keep_rows=df['SECURITY TYPE'].str.contains('bill|note|bond',case=False)
    security_df=df[keep_rows].copy()
 
    # Removes Clutter
    drop_columns=['CUSIP','CALL DATE']
    security_df.drop(columns=drop_columns,inplace=True)


    # Creates a Time-Series Index
    security_df.set_index('MATURITY DATE',inplace=True)
    security_df.index=pd.to_datetime(security_df.index)
    security_df.sort_index(inplace=True)


    # Standardizes Financial Terms
    change_column_names={'RATE':'Coupon',
                         'BUY':'Price Ask',
                         'SELL':'Price Bid'}
    security_df.rename(columns=change_column_names,inplace=True)


    # Formats Numeric Data
    numeric_cols = ['Coupon', 'Price Ask', 'Price Bid', 'YIELD']
    for col in numeric_cols:
        if col in security_df.columns:
            security_df[col] = security_df[col].astype(str).str.replace('%', '', regex=False).astype(float)


    return security_df

Save the clean DataFrame as an Excel Workbook¶

You might want to save the data to an Excel workbook. The create_workbook function requires the DataFrame. If sheet_name and save_config are not assigned, the results are in ‘sheet1’ and the file is saved to the default drive.

def create_workbook(df,sheet_name='sheet1', save_config=None):
    """
    Writes a DataFrame to a specific sheet in an Excel workbook and auto-fits
    column widths for readability.

    Args:
        sheet_name (str): The name of the sheet to create or replace.
        df (pd.DataFrame): The DataFrame to write.
        save_config (dict, optional): Configuration for saving the file, passed
         Keys: 'volume':folder, 'chapter':'subfolder, 'file_name':file name. Defaults to {}.        
    """
    import os
    import re
    import pandas as pd
    import openpyxl
    from openpyxl.utils import get_column_letter
    from IPython.display import display, Markdown as md

    
    # Fix mutable default argument
    if save_config is None:
        save_config = {}

    # --- 1. Sanitize Sheet Name ---
    sane_sheet_name = re.sub(r'[\\*?:/\[\]]', '', str(sheet_name))
    if len(sane_sheet_name) > 31:
        sane_sheet_name = sane_sheet_name[:31]
    if not sane_sheet_name:
        sane_sheet_name = "Sheet1"

    # --- 2. Get Save Path ---
    file_name = save_config.get('file_name', 'output.xlsx')
    if not file_name.endswith('.xlsx'):
        file_name += '.xlsx'
    save_config['file_name']=file_name
    # Assuming save_results is defined elsewhere in your code
    try:
        path_filename = save_results(save_config=save_config)
        if path_filename is None:
            path_filename = file_name
    except NameError:
        # Fallback if save_results is not defined
        path_filename = file_name

    # --- 3. Write and Format ---
    try:
        # Create empty workbook if it doesn't exist to allow 'append' mode
        if not os.path.exists(path_filename):
            pd.DataFrame().to_excel(path_filename, sheet_name="Sheet1")

        # Write DataFrame
        with pd.ExcelWriter(
            path_filename,
            mode='a',
            engine='openpyxl',
            if_sheet_exists='replace',
            datetime_format='YYYY-MM-DD'
        ) as writer:
            # FIXED: Using sane_sheet_name instead of sheet_name
            df.to_excel(writer, sheet_name=sane_sheet_name, index=True)

        # Format with openpyxl
        workbook = openpyxl.load_workbook(path_filename)
        
        # FIXED: Using sane_sheet_name
        try:
            ws = workbook[sane_sheet_name]
        except KeyError:
            print(f"Error: Sheet '{sane_sheet_name}' not found after writing.")
            return

        # Auto-fit columns
        for col_idx, column_cells in enumerate(ws.columns, 1):
            max_length = 0
            column_letter = get_column_letter(col_idx)

            for cell in column_cells:
                try:
                    if cell.value: # Check if cell is not empty
                        cell_length = len(str(cell.value))
                        if cell_length > max_length:
                            max_length = cell_length
                except Exception:
                    pass

            ws.column_dimensions[column_letter].width = max_length + 2

        # Delete default Sheet1 if necessary
        if 'Sheet1' in workbook.sheetnames and sane_sheet_name != 'Sheet1' and len(workbook.sheetnames) > 1:
            del workbook['Sheet1']
            
        workbook.save(path_filename)
        display(md(f"### ***✅ Successfully wrote and formatted sheet {sane_sheet_name} in {path_filename}***"))
        
    except Exception as e:
        display(md("### ❌ **ERROR during Excel write/format:**"))
        print(f"Exception details: {e}")
